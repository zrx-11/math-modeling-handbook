# 第 3 章：数据与统计训练

- **难度**：★★★ | **预估学时**：3 小时 | **前置**：主册第 5、7、10、11 章 | **原书题解定位**：第 5 章 p59–67、第 7 章 p84–90、第 10 章 p103–126、第 11 章 p127–132

## 学习目标

学完本章，你能：

- 手算一条最小二乘直线，并算出残差平方和；
- 完整做一次单样本 t 检验，把结论写成评审能接受的话；
- 判断一组数据是否适合直接做回归，还是先要处理共线性。

## 一句话核心

统计题的错误很少出在算错，多半出在「假设不满足还硬做」和「结论说得比证据强」。

## 训练题与解答

### 题 1（最小二乘拟合）

数据：x = 0, 1, 2, 3；y = 1, 2, 4, 5。求拟合直线并算残差平方和。

**解**：x̄ = 1.5，ȳ = 3。

Sxy = (−1.5)(−2) + (−0.5)(−1) + (0.5)(1) + (1.5)(2) = 3 + 0.5 + 0.5 + 3 = 7。
Sxx = 2.25 + 0.25 + 0.25 + 2.25 = 4.75。
斜率 b = 7/4.75 = 1.474，截距 a = 3 − 1.474×1.5 = 0.789。

预测值：0.789、2.263、3.737、5.211。
残差：0.211、−0.263、0.263、−0.211。
残差平方和 = 0.045 + 0.069 + 0.069 + 0.045 ≈ 0.23。

结论：y ≈ 0.79 + 1.47x。**易错点**：把 Sxx 算成 ∑x² = 14，那是没中心化的写法，会得到错误斜率。

### 题 2（单样本 t 检验）

某零件标准长度 8 mm，抽 5 件测得 8、10、9、11、12，问是否显著偏离 8（α = 0.05）。

**解**：x̄ = 10，偏差 −2、0、−1、1、2，平方和 10，s² = 10/4 = 2.5，s = 1.581。
SE = 1.581/√5 = 0.707。
t = (10 − 8)/0.707 = 2.828，df = 4。
双侧 5% 临界值 t₀.₀₂₅,₄ = 2.776。2.828 > 2.776，拒绝 H₀。

结论：「在 5% 显著性水平下，样本均值与 8 mm 存在显著差异，估计均值 10 mm，95% 置信区间约 [8.04, 11.96]」。

**易错点**：算出 t 大于临界值却写「证明均值是 10」，统计只能说不拒绝或拒绝，不能说证明。

### 题 3（共线性诊断）

某回归有 4 个自变量，相关矩阵中 x₁ 与 x₂ 的相关系数为 0.98，x₃ 与 x₄ 为 0.15。问该怎么处理。

**解**：x₁ 与 x₂ 高度相关，直接回归会出现系数符号反常、方差膨胀。

三种处理：

1. 删掉一个：若业务上 x₂ 可由 x₁ 解释，保留更有解释力的那个。
2. 合并：用 x₁ + x₂ 或均值作为一个新变量。
3. 换方法：用主成分回归或偏最小二乘，把相关变量打包成成分。

处理前后都要报告 VIF。VIF > 10 通常视为严重共线，计算式 VIFⱼ = 1/(1 − Rⱼ²)，Rⱼ² 是第 j 个变量被其余变量回归的解释度。

## 自测题（答案与解析）

### Q1 【单选】最小二乘斜率公式的分母是？
- A. ∑xᵢ²
- B. ∑(xᵢ − x̄)²
- C. ∑yᵢ²
- D. n
**答案**：B
**解析**：分母是 x 的中心化平方和，未中心化会引入截距相关项。

### Q2 【单选】t = 2.83、临界值 2.78，正确结论是？
- A. 证明均值等于 8
- B. 在 5% 水平下拒绝原假设
- C. 样本一定有问题
- D. 需要增大 α 才能判断
**答案**：B
**解析**：t 超过临界值即落入拒绝域，结论是拒绝 H₀，而非证明任何事。

### Q3 【填空】VIF 大于________通常视为严重多重共线性。
**答案**：10
**解析**：经验阈值，超过 10 说明该变量被其余变量解释程度过高。

## 复习锚点

- 拟合先中心化，斜率 = 协方差/方差。
- 检验结论只有「拒绝」与「不拒绝」，没有「证明」。
- 共线三招：删、合并、换方法。
