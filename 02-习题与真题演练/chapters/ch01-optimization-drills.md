学完本章，你能：

- 不看答案独立解一个二元线性规划，并列出全部顶点；
- 判断整数最优与松弛最优的差距，说明为什么不能取整；
- 把一段文字需求翻译成目标规划的三组约束。

## 训练题与解答

### 题 1（线性规划，手算）

max z = 5x₁ + 4x₂，s.t. 2x₁ + 3x₂ ≤ 12，2x₁ + x₂ ≤ 8，x₁, x₂ ≥ 0。

**解**：列顶点。

- 与 x₂ 轴交点：x₁ = 0 时 3x₂ ≤ 12 → (0, 4)，z = 16。
- 与 x₁ 轴交点：x₂ = 0 时 2x₁ ≤ 8 → (4, 0)，z = 20。
- 两约束交点：2x₁ + 3x₂ = 12 与 2x₁ + x₂ = 8 相减得 2x₂ = 4，x₂ = 2，代回 x₁ = 3，(3, 2)，z = 15 + 8 = 23。
- 还要检查交点是否满足全部约束：2×3 + 3×2 = 12 恰好取等，2×3 + 2 = 8 取等，可行。

最优 (3, 2)，z = 23。**易错点**：漏掉 (0,4) 这一顶点；或把交点算成 (3, 2) 后忘记代回验证。

### 题 2（整数规划，松弛与取整对比）

max z = 4x₁ + 3x₂，s.t. 2x₁ + x₂ ≤ 9，x₁ + 2x₂ ≤ 8，x₁, x₂ ≥ 0 且为整数。

**解**：先解松弛。两约束交点：第一式乘 2 得 4x₁ + 2x₂ = 18，减去第二式得 3x₁ = 10，x₁ = 3.333，x₂ = 2.333，z = 13.333 + 7 = 20.333。

枚举附近整数点：

| 点 | 约束检查 | z |
|---|---|---|
| (3, 2) | 8 ≤ 9，7 ≤ 8 | 18 |
| (4, 1) | 9 ≤ 9，6 ≤ 8 | 19 |
| (2, 3) | 7 ≤ 9，8 ≤ 8 | 17 |
| (3, 3) | 9 ≤ 9，9 > 8 不可行 | — |

最优 (4, 1)，z = 19。松弛值 20.333 与整数最优 19 的差叫**整数间隙**，它说明取整必然损失。

### 题 3（目标规划，只建模）

某厂两产品每件利润 3 千元与 2 千元，用工 2 小时与 1 小时。要求利润不低于 60 千元，用工不超过 45 小时。利润每差 1 千元罚 4 个单位，用工每超 1 小时罚 1 个单位，且利润优先级更高。

**解**：设产量 x₁、x₂，偏差变量 d₁⁻、d₁⁺、d₂⁻、d₂⁺ 全非负。

```text
min P₁·4d₁⁻ + P₂·1d₂⁺
s.t. 3x₁ + 2x₂ + d₁⁻ − d₁⁺ = 60
     2x₁ + x₂ + d₂⁻ − d₂⁺ = 45
     x₁, x₂ ≥ 0，d 全 ≥ 0
```

**易错点**：利润不足用 d₁⁻、用工超出用 d₂⁺，两个方向写反是这类题最常见的失分。P₁ 与 P₂ 表示优先级，不是权重，写成分层求解。

## 自测题（答案与解析）

### Q1 【单选】线性规划题列顶点时，最容易漏掉的是？
- A. 两约束交点
- B. 与坐标轴的交点
- C. 原点
- D. 目标函数等值线上的点
**答案**：B
**解析**：很多人只算约束交点，忘记坐标轴截距也是顶点，可能正好是最优点。

### Q2 【单选】整数间隙指的是？
- A. 两个整数解之间的距离
- B. 松弛最优值与整数最优值之差
- C. 约束个数与变量个数之差
- D. 目标系数的最大值与最小值之差
**答案**：B
**解析**：松弛允许小数，整数不允许，两者最优值之差就是间隙。

### Q3 【填空】目标规划中，若要求「利润不低于 60」，不足部分用偏差变量________表示。
**答案**：d₁⁻
**解析**：负偏差表示实际值低于目标，正偏差表示超出。

## 复习锚点

- 列顶点要算三类：轴截距、约束交点、原点。
- 整数最优必在松弛最优附近，但取整不一定可行。
- 目标规划先定方向：不足用负偏差，超出用正偏差。
