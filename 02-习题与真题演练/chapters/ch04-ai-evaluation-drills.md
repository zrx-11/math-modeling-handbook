学完本章，你能：

- 为一个小规模 TSP 设计完整的遗传算法五件套；

## 一句话核心

## 训练题与解答

### 题 1（遗传算法设计）

8 个城市，坐标已知，求最短遍历回路。写出编码、适应度、选择、交叉、变异与终止条件。

**解**：

- **编码**：整数序列，如 [3,1,5,2,8,4,7,6]，表示访问顺序。
- **适应度**：f = 1/总路程。路程越短适应度越高。
- **选择**：锦标赛，每次随机取 3 个个体，留最短的。
- **交叉**：顺序交叉（OX）。父代 A = [1 2 3 4 5 6 7 8]，B = [4 5 2 1 8 7 6 3]。取 A 的片段 [3 4 5]，剩余位置按 B 的顺序补 2、1、8、7、6，得 [2 1 8 3 4 5 7 6]。
- **变异**：随机交换两个位置，或反转一段（2-opt）。
- **终止**：迭代 500 代，或连续 50 代最优值不改进。

参数：种群 100，交叉率 0.8，变异率 0.05，精英保留 2 个。

报告要求：独立运行 20 次，给出最好、平均、标准差。只报一次最好值不合格。

### 题 2（综合评价）

四个方案，三个指标（成本、质量、交付），已标准化为 0–1 且统一为越大越好：S1 (0.9, 0.5, 0.6)、S2 (0.7, 0.8, 0.5)、S3 (0.6, 0.9, 0.7)、S4 (0.5, 0.6, 0.9)。权重 0.4、0.35、0.25，排序。

**解**：

- S1 = 0.4×0.9 + 0.35×0.5 + 0.25×0.6 = 0.36 + 0.175 + 0.15 = 0.685
- S2 = 0.28 + 0.28 + 0.125 = 0.685
- S3 = 0.24 + 0.315 + 0.175 = 0.73
- S4 = 0.20 + 0.21 + 0.225 = 0.635

排序 S3 > S1 = S2 > S4。S1 与 S2 并列，说明成本优势恰好被质量劣势抵消。

**灵敏度**：把成本权重从 0.4 提到 0.6（质量 0.25、交付 0.15）：

- S1 = 0.54 + 0.125 + 0.09 = 0.755
- S2 = 0.42 + 0.20 + 0.075 = 0.695
- S3 = 0.36 + 0.225 + 0.105 = 0.69

排序变成 S1 > S2 > S3，冠军换了人。这就是为什么权重必须做灵敏度，且要在论文里写明。

### 题 3（预测对比）

销量序列 10、12、14、15、17，分别用 3 期移动平均与 α = 0.5 的指数平滑预测下一期。

**解**：

- 移动平均：(14 + 15 + 17)/3 = 15.33。
- 指数平滑：S₁ = 10，S₂ = 0.5×12 + 0.5×10 = 11，S₃ = 12.5，S₄ = 13.75，S₅ = 15.375。

两者接近，差别在记忆长度：移动平均只看最近 3 期，指数平滑对所有历史加权，α 越小记忆越长。数据有突变时移动平均反应更快，平稳时指数平滑更稳。

## 自测题（答案与解析）

### Q1 【单选】遗传算法中精英保留的作用是？
- A. 增加种群规模
- B. 防止最优个体在迭代中丢失
- C. 提高变异率
- D. 缩短编码长度
**答案**：B
**解析**：把当代最优直接复制到下一代，避免选择与变异破坏已找到的好解。

### Q2 【单选】权重从 0.4/0.35/0.25 改成 0.6/0.25/0.15，冠军变化说明？
- A. 数据算错了
- B. 排序对权重敏感，必须做灵敏度
- C. 应该取平均权重
- D. 评价方法无效
**答案**：B
**解析**：权重代表偏好，偏好变则排序变，这是评价方法的固有性质。

### Q3 【填空】指数平滑中 α 越小，记忆长度越________。
**答案**：长
**解析**：α 小则历史权重衰减慢，长期数据影响更大。

## 复习锚点

- 启发式要给完整参数表与多次运行分布。
- 评价要给权重来源与灵敏度。
- 移动平均看窗口，指数平滑看 α。
