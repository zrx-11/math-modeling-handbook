# 数学建模学习手册

五册一套，从零基础走到能交出一份合规的竞赛论文。总入口是 `index.html`，单文件、离线可开、可直接挂 GitHub Pages。

## 一、这套东西是什么

| 册 | 目录 | 内容 | 适合什么时候读 |
|---|---|---|---|
| 起点 | `00-零基础起步/` | 5 章：建模是什么、数学预备、工具、论文骨架、72 小时流程 | 第一次接触建模 |
| 主干 | `01-数学建模算法与应用/` | 16 章，对应《数学建模算法与应用》第 3 版全部章目 | 系统学方法 |
| 练手 | `02-习题与真题演练/` | 4 章 12 道手算题 + 原书题解页码 | 学完一章立刻做 |
| 排版 | `03-LaTeX与论文排版/` | 6 章，从装环境到套论文模板 | 有内容要写的时候 |
| 案例 | `04-竞赛论文案例库/` | 3 章，教怎么读 2016–2023 优秀论文、怎么借结构 | 最后检验自己的方案 |

跨书的推荐顺序、概念映射、综合检验在 `00-跨书总览/`。

## 二、怎么用

1. 双击 `index.html`，浏览器直接打开，不需要联网、不需要装任何东西。
2. 顶部切换五册与跨书总览，左侧按「路径 / 章节 / 概念 / 测验 / 卡片 / 术语 / 模式 / 速查」导航。
3. 搜索框覆盖全部五册，输入关键词即可跳转。
4. 学习进度存在浏览器本地（localStorage），换页面不丢，清缓存会清空。
5. 每册另有单书伴侣 HTML，可单独发给队友：

| 册 | 单书文件 |
|---|---|
| 零基础起步 | `00-零基础起步/start学习伴侣.html` |
| 算法与应用 | `01-数学建模算法与应用/modeling学习伴侣.html` |
| 习题演练 | `02-习题与真题演练/exercises学习伴侣.html` |
| LaTeX | `03-LaTeX与论文排版/latex学习伴侣.html` |
| 案例库 | `04-竞赛论文案例库/cases学习伴侣.html` |

## 三、部署 GitHub Pages

`.nojekyll` 已放在根目录，作用是关闭 Jekyll，保证中文目录名与 `_` 开头的目录原样托管。缺了它，`_build/` 这类型目录会被忽略。

三步：

```bash
# 1. 进入解压后的目录，初始化仓库
git init
git add .
git commit -m "数学建模学习手册"

# 2. 推到自己的仓库（先在 GitHub 建一个空仓库）
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git branch -M main
git push -u origin main

# 3. 网页上设置：Settings → Pages → Source 选 Deploy from a branch
#    Branch 选 main，目录选 /(root)，Save
```

等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

排错：

- 页面 404：确认根目录有 `index.html`，且 Pages 的目录选的是 root 不是 `/docs`。
- 中文文件名 404：确认 `.nojekyll` 在根目录（注意是空文件，不是空文件夹）。
- 图示空白：先看是否断网。脚本按 npmmirror → unpkg → jsdelivr 顺序自动回退，国内网络下第一个源通常可用；三个都失败才降级为源码显示。
- 样式全丢：确认 `index.html` 是完整单文件，没有被编辑器截断。
- 改了内容没生效：Pages 有缓存，等两分钟或强制刷新（Ctrl+F5）。

## 五、已知限制

- 原始 PDF 与 435 MB 论文压缩包没有打进手册。手册是学习产物，不是电子书仓库；需要读原文时用附件里的原文件。
- 2019 年的优秀论文是扫描图（每篇多张 JPG），2020 年只有 3 篇，案例库第 2 章已标明。
- 《LaTeX 入门》原书 587 页，本册只取比赛用得到的六件事，不是全书的替代品。
- 单书伴侣内的测验与总入口的测验是同一批题，进度分别存在各自的浏览器存储里，不互通。
