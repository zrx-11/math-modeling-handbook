# 模式与框架库

## 框架：题型识别四问

1. 要不要给出一个方案或数值？要 → 规划类，第 1–3、16 章。
2. 对象之间有没有连接关系？有 → 图论，第 4 章。
3. 有没有时间序列或状态演化？有 → 微分方程、差分方程、预测，第 6、8、15 章。
4. 要不要从一堆对象里分组、排序、挑出重要变量？要 → 多元分析与评价，第 9–11、14 章。

四问的答案可以叠加。真实赛题常常是「先用评价排序，再对前几名做规划」。

## 决策规则

- 变量全为整数且规模小于 50 → 精确整数规划；大于 50 → 启发式 + 报告近似。
- 数据点少于 15 且单调 → 灰色预测或拟合；有明确机制 → 微分方程；长序列有季节性 → ARIMA。
- 指标超过 5 个且量纲不一 → 先标准化再评价，不要直接加权求和。
- 两个目标明显冲突 → 先画 Pareto 前沿，再让决策者选点，不要自己拍权重。

## 反模式

- **把相关当因果**：相关系数 0.8 只说明同向变化，写「A 导致 B」需要额外证据。
- **只报一次最好结果**：启发式算法跑一次得 17，就宣称最优 17，无法排除运气。
- **用复杂模型掩盖假设缺失**：神经网络拟合得再好，也说不出机制，评委要看的是解释。
- **灵敏度写成自我表扬**：只写「模型稳健」不给扰动范围和结论变化，等于没写。
