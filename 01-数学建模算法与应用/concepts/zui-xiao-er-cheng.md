# 最小二乘

<!--chapters: ch05,ch07,ch11-->

- **难度**：基础 | **涉及章节**：第 5、7、11 章

## 一句话定义

在所有候选参数里，挑使残差平方和最小的那一组。

## 为什么重要

它是拟合、回归、PLS 的共同底座。理解了它，第 5、7、11 章的公式就都是同一件事的不同包装。

## 图示

```mermaid
flowchart LR
    A[数据点] --> B[假设函数形式]
    B --> C[算残差平方和]
    C --> D[对参数求导令零]
    D --> E[解出参数]
```

## 详解

一元直线拟合的解析解：斜率 = 协方差 / 方差，截距 = 均值差。多元时写成 (XᵀX)⁻¹Xᵀy，共线会让 XᵀX 接近奇异，系数爆炸。

类比：往几个点中间拉一根橡皮筋，它最终停在总拉伸量最小的位置。失效边界：橡皮筋对所有点等权，有异常值时会被单点拽偏，这时要用稳健回归。

## 常见误解

别以为最小二乘只适合直线——实际上任何线性于参数的模型都能用，多项式拟合也是线性的。

## 在书中出现的脉络

| 章节 | 语境 | 关键结论 |
|---|---|---|
| 第 5 章 | 直线拟合 | 斜率 1.5、截距 0.333 |
| 第 7 章 | 回归 | 与假设检验配套使用 |
| 第 11 章 | 共线性 | XᵀX 病态导致系数不稳 |

## 相关概念

- 前置：矩阵、导数
- 后续：岭回归、偏最小二乘
