# 数学建模算法与应用 · 抽认卡

### 卡片：线性规划的最优解一定在哪里？
- **背面**：可行域的顶点（或边界），只要最优解存在
- **标签**：线性规划, 几何
- **章节**：ch01

### 卡片：影子价格的含义？
- **背面**：约束右端项每增加一个单位，目标函数能增加的量，等于对偶变量
- **标签**：线性规划, 对偶
- **章节**：ch01

### 卡片：影子价格为 0 说明什么？
- **背面**：该约束未起作用，资源有闲置，追加投入不改变最优值
- **标签**：线性规划, 排错
- **章节**：ch01

### 卡片：为什么整数规划不能解完取整？
- **背面**：取整可能违反约束，也可能错过更优的格点，例：max 3x₁+4x₂, 3x₁+5x₂≤8 真正最优是 (1,1) 得 7
- **标签**：整数规划, 常见错误
- **章节**：ch02

### 卡片：0-1 变量怎么表达「最多选一个」？
- **背面**：y_A + y_B ≤ 1
- **标签**：整数规划, 建模技巧
- **章节**：ch02

### 卡片：分枝定界的剪枝依据？
- **背面**：节点的线性松弛值已不如现有整数解，该分支不可能更优
- **标签**：整数规划, 算法
- **章节**：ch02

### 卡片：凸规划的好处？
- **背面**：局部最优即全局最优，梯度类算法不会停在半山腰
- **标签**：非线性规划
- **章节**：ch03

### 卡片：KKT 互补松弛的含义？
- **背面**：约束未起作用时乘子为零，起作用时乘子可正，λᵢgᵢ = 0
- **标签**：非线性规划, 理论
- **章节**：ch03

### 卡片：Dijkstra 的前提条件？
- **背面**：边权非负；有负权要改 Bellman-Ford 或 Floyd
- **标签**：图论, 算法
- **章节**：ch04

### 卡片：最短路与最小生成树的区别？
- **背面**：前者求一对点之间路径最短，后者求连通全图的边集总权最小
- **标签**：图论
- **章节**：ch04

### 卡片：n 个点的生成树有几条边？
- **背面**：n−1 条，且无环、连通
- **标签**：图论, 基础
- **章节**：ch04

### 卡片：插值与拟合的根本区别？
- **背面**：插值必须穿过每个数据点，拟合只要求整体误差最小
- **标签**：插值拟合
- **章节**：ch05

### 卡片：Runge 现象说明什么？
- **背面**：等距节点上提高多项式次数，边缘振荡加剧，误差反而变大
- **标签**：插值拟合, 常见错误
- **章节**：ch05

### 卡片：三次样条比高次多项式好在哪？
- **背面**：分段低次、节点处一二阶导数连续，稳定且光滑
- **标签**：插值拟合
- **章节**：ch05

### 卡片：微分方程建模的第一步？
- **背面**：找出「变化率等于什么」，即把机制写成 dX/dt = f
- **标签**：微分方程
- **章节**：ch06

### 卡片：Euler 法与 RK4 的精度阶数？
- **背面**：Euler 一阶，RK4 四阶；步长减半可检验收敛性
- **标签**：微分方程, 数值解
- **章节**：ch06

### 卡片：R₀ 的定义与含义？
- **背面**：R₀ = β/γ，一个感染者平均传染的人数，大于 1 疫情扩散
- **标签**：微分方程, 传染病
- **章节**：ch06

### 卡片：p 值的准确含义？
- **背面**：H₀ 为真时，出现当前或更极端结果的概率，不是 H₀ 为真的概率
- **标签**：统计, 假设检验
- **章节**：ch07

### 卡片：不拒绝 H₀ 该怎么表述？
- **背面**：没有足够证据说明有差异，不能说「两者相等」
- **标签**：统计, 表述
- **章节**：ch07

### 卡片：Bootstrap 的核心操作？
- **背面**：有放回重抽样，重复计算统计量，用其分布代替理论抽样分布
- **标签**：统计
- **章节**：ch07

### 卡片：一阶差分方程 xₙ₊₁ = axₙ + b 的平衡点？
- **背面**：x* = b/(1−a)，稳定条件 |a| < 1
- **标签**：差分方程
- **章节**：ch08

### 卡片：Leslie 矩阵的结构？
- **背面**：首行各年龄组繁殖率，次对角线为存活率，主特征值定长期增长率
- **标签**：差分方程, 种群
- **章节**：ch08

### 卡片：SVM 的间隔公式？
- **背面**：2/‖w‖，要求支持向量处 wᵀx + b = ±1
- **标签**：SVM
- **章节**：ch09

### 卡片：SVM 的 C 增大意味着什么？
- **背面**：更不容忍越界，间隔变窄，方差上升，容易过拟合
- **标签**：SVM, 调参
- **章节**：ch09

### 卡片：核函数的作用？
- **背面**：隐式映射到高维，使线性不可分变可分，无需算高维坐标
- **标签**：SVM
- **章节**：ch09

### 卡片：聚类与判别的区别？
- **背面**：聚类无标签按相似度分组，判别有标签学分类规则
- **标签**：多元分析
- **章节**：ch10

### 卡片：PCA 的贡献率是什么？
- **背面**：某主成分特征值占全部特征值之和的比例，即保留的方差份额
- **标签**：多元分析, 降维
- **章节**：ch10

### 卡片：PCA 与因子分析的区别？
- **背面**：PCA 是线性变换无模型假设，因子分析假设潜在因子生成观测变量
- **标签**：多元分析
- **章节**：ch10

### 卡片：多重共线性的后果？
- **背面**：系数方差大、符号反常、可解释性丧失，VIF > 10 是常见判据
- **标签**：回归, 偏最小二乘
- **章节**：ch11

### 卡片：PLS 与 PCA 的关键差别？
- **背面**：PLS 提取成分时同时考虑与 Y 的协方差，PCA 只看 X 的方差
- **标签**：偏最小二乘
- **章节**：ch11

### 卡片：模拟退火的接受概率？
- **背面**：P = exp(−Δ/T)，Δ 为变差量，T 为温度，温度高更易接受差解
- **标签**：启发式算法
- **章节**：ch12

### 卡片：遗传算法五件套？
- **背面**：编码、适应度、选择、交叉、变异
- **标签**：启发式算法
- **章节**：ch12

### 卡片：启发式结果必须报告什么？
- **背面**：多次独立运行的最好值、平均值、标准差，而不只是最好值
- **标签**：启发式算法, 论文规范
- **章节**：ch12

### 卡片：图像在计算机里是什么？
- **背面**：灰度图是 m×n 矩阵，彩色图是 m×n×3 的三通道矩阵
- **标签**：图像处理
- **章节**：ch13

### 卡片：均值滤波与中值滤波的取舍？
- **背面**：均值去噪但糊边，中值保边、适合椒盐噪声
- **标签**：图像处理
- **章节**：ch13

### 卡片：综合评价的四步？
- **背面**：定指标、标准化、定权重、合成排序
- **标签**：综合评价
- **章节**：ch14

### 卡片：熵权法权重反映什么？
- **背面**：指标在方案间的区分度，不是业务重要性
- **标签**：综合评价, 权重
- **章节**：ch14

### 卡片：TOPSIS 的排序依据？
- **背面**：到正理想解与负理想解的欧氏距离，离正近、离负远者优
- **标签**：综合评价
- **章节**：ch14

### 卡片：GM(1,1) 适合什么数据？
- **背面**：小样本、近似指数趋势的单调序列，先做级比检验
- **标签**：预测
- **章节**：ch15

### 卡片：预测精度必须包含什么？
- **背面**：样本外检验指标（MAE/RMSE/MAPE）与预测区间
- **标签**：预测, 论文规范
- **章节**：ch15

### 卡片：Pareto 有效解？
- **背面**：不存在所有目标都不差且至少一个更好的解，多目标输出的是前沿
- **标签**：多目标
- **章节**：ch16

### 卡片：加权和法的局限？
- **背面**：非凸 Pareto 前沿上会漏掉中间解，只能取到支撑点
- **标签**：多目标
- **章节**：ch16

### 卡片：目标规划中的偏差变量？
- **背面**：d⁺ 为超出目标的量，d⁻ 为不足的量，两者不能同时非零
- **标签**：多目标, 目标规划
- **章节**：ch16
