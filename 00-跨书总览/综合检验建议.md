# 综合检验建议

## 跨书整合题

### 题 1：从读到写（跨度最大）
- 涉及：案例库第 1 章、算法与应用第 1、14 章、LaTeX 第 6 章
- 要求：读一篇 2021 年 A 题论文，按六步法拆解，然后用你自己的假设重写一份 8 页论文，含三线表、两条公式、五篇参考文献。
- 评分要点：
  1. 方法卡五字段齐全，硬伤判断有依据；
  2. 新论文的假设与原论文至少两处不同，且改动写清；
  3. 所有数值可追溯到程序输出；
  4. 四级标题编号连续，文献无 `[?]`。

### 题 2：建模与验证闭环
- 涉及：算法与应用第 1、14 章，习题演练第 1、4 章
- 要求：给一组四方案三指标的数据，先做加权评价，再做权重灵敏度，最后用线性规划给出「在预算约束下如何改方案使综合得分最大」。
- 评分要点：
  1. 标准化方向统一，权重来源写明；
  2. 灵敏度至少两组权重，排序变化要解释；
  3. 规划模型变量与评价指标对应，约束量纲正确；
  4. 结论区分「评价结论」与「优化结论」。

### 题 3：预测与决策
- 涉及：算法与应用第 15、6 章，习题演练第 2、3 章
- 要求：用指数平滑预测 6 期需求，再用预测值做库存优化，最后做一次参数扰动，说明策略稳健性。
- 评分要点：
  1. 预测方法与 α 的选择有依据；
  2. 预测误差有指标（MAE 或 MAPE）；
  3. 优化模型用预测值而非原始值；
  4. 扰动后给出「策略何时失效」的边界。

### 题 4：全流程模拟（72 小时压缩版）
- 涉及：起步册第 5 章 + 全部四册
- 要求：用 12 小时完成一道往届题：读题 1 小时、建模 4 小时、求解 3 小时、写作 3 小时、检查 1 小时。
- 评分要点：
  1. 有明确的里程碑时间表并基本执行；
  2. 摘要含每问方法与关键数字；
  3. 至少一处灵敏度或误差分析；
  4. 交卷前按格式清单自查并记录。

## 进阶路线

1. **偏理论**：算法与应用第 3、9、11 章 → 补凸优化与统计学习教材 → 复现一篇论文的完整推导。
2. **偏工程**：第 12、13 章 → 学 Python 科学计算栈（numpy/scipy/sklearn）→ 把 16 章的例子全部代码化。
3. **偏竞赛**：案例库同题三篇 → 组队做三次完整模拟 → 建立自己的模板库与代码库。
